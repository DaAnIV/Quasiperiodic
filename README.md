# Quasiperiodic

> This is a repo for experimenting with numeric caclulations relating to the discrete schrodinger operator on a quasiperiodic chain.

You can use the Butterfly.py script to create a plot as a PNG image or view the Butterfly.ipynb notebook for a deeper explanation on the creation of the butterfly.

This was used to generate the butterfly figures in the paper "A review of a work by Raymond: Sturmian Hamiltonians with a large coupling constant – periodic approximations and gap labels" [^1]

[^1]: Ram Band, , Siegfried Beckus, Barak Biber, Laurent Raymond, Yannik Thomas. "A review of a work by Raymond: Sturmian Hamiltonians with a large coupling constant – periodic approximations and gap labels." (2024). [doi](https://doi.org/10.48550/arXiv.2409.10920)
